# 孤城回响

[English](README.md) | [中文](README_zh.md)

## 概述

"孤城回响"是一个使用 Three.js 构建的大气 3D 网页体验，让用户沉浸在一个荒凉、废弃的城市景观中。在雨水落下、远处灯光在夜色中闪烁的同时，探索曾经繁华、如今笼罩在黑暗和神秘中的大都市废墟。

## 特点

- **沉浸式 3D 环境**：探索一个详细的废弃城市，包含建筑物、街道和大气元素
- **动态天气系统**：体验雨、雾和尘埃粒子，营造出忧郁的氛围
- **昼夜循环**：带有星空和微妙照明的黑暗夜间环境
- **逼真的照明**：动态照明系统，包括闪烁的灯光、月光和偶尔的闪电
- **第一人称控制**：使用 WASD 键和鼠标视角导航环境
- **碰撞检测**：逼真的移动体验，碰撞检测防止穿过建筑物
- **大气界面**：极简主义 UI，带有指南针辅助导航
- **响应式设计**：适应不同的屏幕尺寸和分辨率

## 技术细节

- 使用 Three.js 进行 3D 渲染
- 使用指针锁定控制实现第一人称相机移动
- 自定义着色器实现天空和天气效果
- 使用光线投射进行碰撞检测
- 使用 Vite 作为构建工具，实现快速开发和优化的生产构建

## 控制

- **W, A, S, D** - 向前、向左、向后、向右移动
- **鼠标** - 环顾四周
- **点击** - 锁定/解锁鼠标指针

## 安装

1. 克隆仓库：
```bash
git clone https://github.com/zym9863/echoes-of-the-lonely-city.git
cd echoes-of-the-lonely-city
```

2. 安装依赖：
```bash
npm install
```

3. 运行开发服务器：
```bash
npm run dev
```

4. 构建生产版本：
```bash
npm run build
```

5. 预览生产构建：
```bash
npm run preview
```

## 项目结构

- `/src` - 源代码
  - `/city` - 城市生成和建筑组件
  - `/effects` - 天气和视觉效果
  - `/lighting` - 照明系统组件
  - `main.js` - 主应用程序入口点
  - `style.css` - 全局样式
